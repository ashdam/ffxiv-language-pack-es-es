# Language pack en español para FFXIV (no oficial)

Traducción al español de los textos de Final Fantasy XIV para el plugin de Dalamud
**Gubal Library**. No modifica los ficheros originales del juego.

Instalación, ejemplos, estado de la traducción y cómo reportar erratas:
**[eorzealocalized.com/es/](https://eorzealocalized.com/es/)**

Cómo colaborar con la traducción:
**[eorzealocalized.com/localize/es-es.html](https://eorzealocalized.com/localize/es-es.html)**

`glossary/tribes.json` fija los nombres españoles de las tribus y sus flexiones admitidas en `forms`.
Las entradas no incluyen artículo; la concordancia depende del contexto.

`glossary/expressions.json` contiene expresiones completas admitidas para la comprobación ortográfica.
Cada variante de género y número ocupa una entrada; sus palabras sueltas siguen comprobándose.
Las locuciones importadas proceden de [Wikcionario, a través de Kaikki](https://kaikki.org/eswiktionary/),
con atribución a sus colaboradores y licencia [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
